# Бубу — шуточный шифр

[![English](https://img.shields.io/badge/README-English-blue)](README.en.md)

Превращает русский и английский текст в произносимую абракадабру и обратно. Придумано по мотивам мема «PITIPIWPIW WIW WIW».

```
Привет, мир!   →  Вукапюбю, дюлу!       (версия 2)
Привет, мир!   →  Пмареда, фенху!       (версия 1)
Hello, world!  →  Lopkumge, ttopbymme!  (версия 1)
```

Сайт работает целиком в браузере: текст никуда не отправляется.

## Возможности

- **Две версии шифра** — версия 2 «милота» (по умолчанию) и версия 1 «классика».
- **Переключатели версии 2** — «Сочетания» и «Ритм», кнопки с фиксацией. Появляются, когда выбрана версия 2.
- **Живая конвертация** — результат обновляется прямо во время ввода.
- **Ключ (необязательно)** — число задаёт сдвиг, слово — ключ Виженера.
- **Строгая расшифровка** — если текст не мог получиться из шифра, сайт пишет, где именно ошибка:
  ```
  Не удалось расшифровать.
  Символ 3, слово «Паш»: буква «ш» не используется в шифре.
  ```
- **Интерфейс на русском и английском** — язык выбирается по браузеру, переключатель в углу.
- **Совместимость** — русский текст шифруется точно так же, как скриптом `bubu_cipher.py`.

## Версия 2 — милота

Мягкие слоги с хвостиками: `пан`, `бум`, `пиу`, `мяу`. Только русский текст.

1. Слог = начальная согласная + гласная + необязательный хвостик. Начальные согласные: `п м б т л н д к р в`, гласные: `а и у о я ю`, хвостики: `у н м й`.
2. Текст режется на тройки символов, каждая тройка становится двумя слогами. Частые тройки получают самые короткие слоги. Остаток из одного или двух символов занимает один или два слога.
3. Заглавные буквы сохраняются: первая — регистром результата, остальные — невидимым маркером внутри шифра.
4. **Сочетания** добавляют лёгкие начала слогов `пр бр тр кл пл`.
5. **Ритм** шифрует пробелы и дефисы вместе со словами и разбивает результат на куски по 2–3 слога, как песню: `Пабам-дола, пимма`.
6. Ключ сдвигает начальную согласную каждого слога по кругу.

```
Привет, мир  →  Вукапюбю, дюлу
+ сочетания  →  Вунуботю, витя
+ ритм       →  Пабам-дола, пимма
+ оба        →  Паплу-рамя, бропу
```

## Версия 1 — классика

Русский и английский: каждое слово остаётся в своём алфавите.

1. Буквы пронумерованы по частоте: `о = 0, е = 1, а = 2, …` для русского и `e = 0, t = 1, a = 2, …` для английского.
2. Слово режется на пары букв. Если букв нечётное число, последняя получает пару с маркером конца слова.
3. Пара `(a, b)` превращается в число по схеме «квадратных оболочек»: `m = max(a, b)`, `n = m² + (b, если a = m, иначе m + 1 + a)`. Пары частых букв получают маленькие числа.
4. Маленькое число становится слогом «согласная + гласная», большое — «две согласные + гласная».
5. Ключ сдвигает согласные слогов по кругу из 16 штук. Позиция в ключе-слове переходит к следующей букве на каждой согласной шифротекста.

|                       | Русский                             | English                      |
| --------------------- | ----------------------------------- | ---------------------------- |
| Частотный алфавит     | `оеаинтсрвлкмдпуяыьгзбчйхжшюцщэфъё` | `etaoinshrdlcumwfgypbvkjxqz` |
| Согласные слогов (16) | `пткбдгмнлрсзшхвф`                  | `ptkbdgmnlrszwhvf`           |
| Гласные слогов        | `аоуиеыяю`                          | `aouiey`                     |

Регистр сохраняется только у первой буквы слова: `ПРИВЕТ` после расшифровки станет `Привет`.

В обеих версиях знаки препинания, цифры и прочие символы остаются как есть. Для расшифровки нужны те же версия, переключатели и ключ, что и при шифровании.

## Скрипт на Python

[`exmaple/bubu_cipher.py`](exmaple/bubu_cipher.py) — версия для командной строки, нужен только [uv](https://docs.astral.sh/uv/). Скрипт работает только с русским текстом, английский есть в версии 1 на сайте.

```bash
uv run exmaple/bubu_cipher.py v2 enc "Привет, мир"              # Вукапюбю, дюлу
uv run exmaple/bubu_cipher.py v2 enc -l -r "Привет, мир"        # Паплу-рамя, бропу
uv run exmaple/bubu_cipher.py v1 enc "Привет, мир"              # Пмареда, фенху
uv run exmaple/bubu_cipher.py v2 dec -k фраза "Пулапюпю, дюну"  # Привет, мир
echo "текст" | uv run exmaple/bubu_cipher.py ver2 enc -r        # рубо-бова
```

- `v1` / `v2` — версия (также `ver1`, `ver2`);
- `enc` / `dec` — зашифровать или расшифровать;
- `-l` — сочетания (только v2);
- `-r` — ритм (только v2);
- `-s N` — сдвиг;
- `-k СЛОВО` — ключ Виженера.

В отличие от сайта, скрипт не проверяет шифротекст строго: непонятные символы он может просто пропустить.

## Запуск и публикация

Сборка не нужна. Достаточно открыть `index.html` в браузере или поднять локальный сервер:

```bash
uv run --no-project python -m http.server 8000
```

Сайт публикуется на GitHub Pages через GitHub Actions ([`.github/workflows/pages.yml`](.github/workflows/pages.yml)) при каждом пуше в `master`. Один раз нужно включить это в настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
