# Бубу — шуточный шифр

[![English](https://img.shields.io/badge/README-English-blue)](README.en.md)

Превращает русский и английский текст в произносимую абракадабру и обратно. Придумано по мотивам мема «PITIPIWPIW WIW WIW».

```
Привет, мир!   →  Пмареда, фенху!
Hello, world!  →  Lopkumge, ttopbymme!
```

Сайт работает целиком в браузере: текст никуда не отправляется.

## Возможности

- **Живая конвертация** — результат обновляется прямо во время ввода.
- **Русский и английский** — каждое слово остаётся в своём алфавите: русские слова становятся кириллическими слогами, английские — латинскими. Языки можно смешивать в одном тексте.
- **Ключ (необязательно)** — число задаёт сдвиг Цезаря, слово из русских или английских букв — ключ Виженера.
- **Строгая расшифровка** — если текст не мог получиться из шифра, сайт пишет, где именно ошибка:
  ```
  Не удалось расшифровать.
  Символ 3, слово «Hello»: слог «llo» не соответствует ни одной паре букв.
  ```
- **Интерфейс на русском и английском** — язык выбирается по браузеру, переключатель в углу.
- **Совместимость** — сайт и скрипт `bubu_cipher.py` дают одинаковый результат.

## Как это работает

1. Буквы пронумерованы по частоте: `о = 0, е = 1, а = 2, …` для русского и `e = 0, t = 1, a = 2, …` для английского.
2. Слово режется на пары букв. Если букв нечётное число, последняя получает пару с маркером конца слова.
3. Пара `(a, b)` превращается в число по схеме «квадратных оболочек»: `m = max(a, b)`, `n = m² + (b, если a = m, иначе m + 1 + a)`. Пары частых букв получают маленькие числа.
4. Маленькое число становится слогом «согласная + гласная», большое — «две согласные + гласная».
5. Ключ сдвигает согласные слогов по кругу из 16 штук. Позиция в ключе-слове переходит к следующей букве на каждой согласной шифротекста.

|                       | Русский                             | English                      |
| --------------------- | ----------------------------------- | ---------------------------- |
| Частотный алфавит     | `оеаинтсрвлкмдпуяыьгзбчйхжшюцщэфъё` | `etaoinshrdlcumwfgypbvkjxqz` |
| Согласные слогов (16) | `пткбдгмнлрсзшхвф`                  | `ptkbdgmnlrszwhvf`           |
| Гласные слогов        | `аоуиеыяю`                          | `aouiey`                     |

Знаки препинания, цифры и прочие символы остаются как есть. Регистр сохраняется только у первой буквы слова: `ПРИВЕТ` после расшифровки станет `Привет`.

## Скрипт на Python

[`exmaple/bubu_cipher.py`](exmaple/bubu_cipher.py) — версия для командной строки, нужен только [uv](https://docs.astral.sh/uv/):

```bash
uv run exmaple/bubu_cipher.py enc "Привет, мир"             # Пмареда, фенху
uv run exmaple/bubu_cipher.py enc "Hello, world"            # Lopkumge, ttopbymme
uv run exmaple/bubu_cipher.py enc -s 3 "Привет, мир"        # Брашена, кеспу
uv run exmaple/bubu_cipher.py dec -k фраза "Гнареша, фешву" # Привет, мир
echo "текст" | uv run exmaple/bubu_cipher.py enc -k secret
```

- `enc` / `dec` — зашифровать или расшифровать;
- `-s N` — сдвиг Цезаря;
- `-k СЛОВО` — ключ Виженера.

В отличие от сайта, скрипт не проверяет шифротекст: непонятные символы он просто пропускает.

## Запуск и публикация

Сборка не нужна. Достаточно открыть `index.html` в браузере или поднять локальный сервер:

```bash
uv run --no-project python -m http.server 8000
```

Сайт публикуется на GitHub Pages через GitHub Actions ([`.github/workflows/pages.yml`](.github/workflows/pages.yml)) при каждом пуше в `master`. Один раз нужно включить это в настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
